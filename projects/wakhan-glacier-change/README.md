Wakhan Glacier Change Analysis (2010–2024)

1. Project Overview

This project examines glacier changes in the Wakhan Corridor, Badakhshan Province, Afghanistan, using Geographic Information Systems (GIS) and Remote Sensing techniques.

The study focuses on glacier area changes, glacier retreat, and potential new glacier formation over the study period.

2. Study Area

- Location: Wakhan Corridor
- Province: Badakhshan
- Country: Afghanistan
- Study Period: 2010–2024

3. Objectives

- Monitor glacier area changes over time.
- Identify glacier retreat and potential new ice formation.
- Assess environmental changes associated with climate variability.
- Produce spatial maps and quantitative statistics.

4. Data and Methodology

- Landsat 8 and Landsat 9 satellite imagery
- Normalized Difference Snow Index (NDSI)
- Satellite image preprocessing
- Glacier classification and change detection
- GIS-based spatial analysis
- ArcGIS Pro

5. Key Findings

The analysis identified:

- Approximately 12% glacier retreat.
- Approximately 5% newly classified glacier area.
- Approximately 81% unchanged area.

These percentages represent the classified results of the study.

6. Outputs

- Glacier distribution maps
- Glacier change detection maps
- Spatial statistics
- Environmental analysis
